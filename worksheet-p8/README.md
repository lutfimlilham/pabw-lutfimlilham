# P8 — Profil dan Data JavaScript

## Deskripsi

Proyek ini dibuat untuk memenuhi tugas Pertemuan 8 mata kuliah PABW (Pengembangan Aplikasi Berbasis Web). Proyek ini mempelajari JavaScript Modern ES6+, struktur data, fungsi, dan array methods untuk menampilkan serta mengelola data secara dinamis pada halaman web.

## Fitur Website

* Menampilkan data profil mahasiswa.
* Menampilkan daftar keahlian menggunakan JavaScript.
* Menampilkan daftar proyek beserta teknologi dan status penyelesaiannya.
* Menampilkan daftar film dalam bentuk tabel.
* Menambahkan film baru melalui formulir.
* Mengubah tema website dari terang ke gelap.
* Menampilkan data secara dinamis tanpa menuliskan seluruh data langsung di HTML.

## Materi JavaScript yang Digunakan

* `const` untuk mendeklarasikan variabel.
* Object untuk menyimpan data profil.
* Array untuk menyimpan daftar keahlian, proyek, dan film.
* Function untuk mengolah dan menampilkan data.
* Arrow function untuk menulis fungsi dengan sintaks ringkas.
* Template literal untuk menyusun teks dan elemen HTML.
* Destructuring untuk mengambil properti dari object.
* Optional chaining (`?.`) untuk mengakses properti secara aman.
* Nullish coalescing (`??`) untuk memberikan nilai alternatif.
* Spread operator (`...`) untuk menyalin object dan array.
* `map()` untuk mengolah data menjadi tampilan.
* `filter()` untuk menyaring data.
* `find()` untuk mencari data tertentu.
* DOM manipulation untuk menampilkan data pada halaman web.
* Event listener untuk menangani interaksi pengguna.

## Pengujian

Pengujian dilakukan melalui browser menggunakan server lokal.

Fitur yang diuji:

1. Halaman profil dapat ditampilkan.
2. Daftar keahlian tampil dengan benar.
3. Daftar proyek tampil dengan benar.
4. Film dapat ditambahkan melalui formulir.
5. Tema terang dan gelap dapat digunakan.
6. Data proyek dapat diolah menggunakan `map()`, `filter()`, dan `find()`.
7. Console browser diperiksa untuk mengetahui apakah terdapat error JavaScript.
